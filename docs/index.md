# agent-config-baseline

A strict, vendor-neutral security baseline for the files that configure AI
agents: Agent Skills directories, agent instruction files, and Model Context
Protocol server declarations. Each control has a rationale, an audit
procedure and a remediation, and the `acb` checker evaluates them.
