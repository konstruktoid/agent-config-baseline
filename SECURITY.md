# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/konstruktoid/agent-config-baseline/security/advisories/new).
Do not open a public issue or pull request for a suspected vulnerability.

This project has a single maintainer. Reports are acknowledged within 5 business days. A fix or a
mitigation plan follows as soon as the maintainer can assess the report, and the reporter is
credited unless they ask otherwise.

## Scope

Vulnerabilities in the `acb` checker, the reusable workflow `.github/workflows/acb-check.yml`, and the
published site are in scope. A weakness in a control's wording or coverage is not a vulnerability;
open a regular issue for it.

## Supported versions

Only the latest commit on `main` is supported.
